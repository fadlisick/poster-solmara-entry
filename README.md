Solmara — a vintage flat travel poster for a place that isn't there: a white lighthouse with a golden beam on a crescent cliff over a turquoise bay at golden hour. The poster is rendered locally with Pillow (`draw_poster.py`, 2048 then downscaled to 1024 for clean anti-aliasing) and the entrypoint (`main.py`, stdlib only) validates and copies it to the output directory as `entry.png`.

## Run it

```sh
python3 draw_poster.py && MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
